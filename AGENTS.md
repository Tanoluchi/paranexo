# Agent instructions

## UI rules

Every UI change (landing, `hablemos.html`, figures, designs under `design/`) follows these rules:

- **Responsive**: design and check at 375px, 768px and 1280px+. Adapt layout per breakpoint; never just scale the desktop version down.
- **Hierarchy**: less text, a clearly emphasized CTA, easy to scan.
- **Tokens**: every page loads `styles/landing.css`; use its `:root` custom properties for colors and fonts and keep spacing, radii and shadows consistent. Add a token instead of hard-coding a new value. The palette is the Puente Cauce brand kit (`--terra` Naranja Cauce #EF633C, `--ink` Carbón #20211F, `--cream` Papel #FCFBF8, `--marfil` Marfil #FAF4E8, `--surface` white) plus the AA shades derived from it (`--terra-ink` for small orange text, `--ink-2`, `--paper`, `--line`, `--terra-tint`); blue (`--river*`) only lives inside illustrations and data. Never use `--terra` for small text on light backgrounds. Fonts are Bricolage Grotesque (headings) and DM Sans (text); `--serif` is the legacy display token name.
- **Brand**: the logo is the approved file in `assets/brand/` (`logo-horizontal-color.svg` on light, `logo-horizontal-color-dark.svg` in dark mode, `favicon.svg` as the tab icon on every page); never redraw it or set its name in a font, keep its proportions and clear space, no CSS filters.
- **Glass**: translucent panels (`.glass`, `.liquid`, `.blobs`) are the one rounded material (`--r-glass`, `--r-glass-sm`); cards and surfaces stay square. Text on glass keeps AA through the glass tint, never over a raw liquid field; liquid fields stop moving under reduced motion.
- **Consistency**: buttons, cards, inputs and modals look and behave the same everywhere (reuse `.btn`, `.btn-primary`, `.btn-ghost`). Dark mode is the nav toggle (`.theme-toggle`, `src/theme.mjs`) that sets `data-theme` on `<html>`; the `:root[data-theme="dark"]` token block restyles everything, light is the default and the inline `<head>` script only applies a saved dark choice; illustrations (the app examples and the service demos, `.app-stage`, `.ex-card`) keep the light palette; the hero bridge (`.hero-dots`, `src/hero-dots.mjs`) is drawn as dots in the theme's `--terra`, `--terra-ink` and `--river-ink`; it builds once per page load, then only breathes, glitches, carries pulses along the deck and (fine pointers only) follows the cursor, keeps the copy zone free of dots, pauses off screen and when the tab is hidden, and under reduced motion is the finished bridge drawn once. On accent fills use `var(--cream)` for text so it flips with the fill. The footer (`src/partials/footer.html`, `src/footer.mjs`) is the Paseo del Paraná picture with moving water and falling petals (paused off screen, static under reduced motion); its text always starts below the picture, on solid `--cream`.
- **Accessibility**: meaningful `alt` on images, `aria-label` on icon-only controls, sufficient contrast (WCAG AA), visible focus.
- **States**: implement empty, error, success and loading states, not only the happy path.
